# MineSweeper 💣

## Funktionen ⚡

- Klassisches Minesweeper mit 20 × 20 Feldern.
- 100 Bomben pro Partie 💥
- Erster Klick ist sicher: Um das Startfeld herum wird kein Minenfeld platziert.
- Linksklick: Feld aufdecken 🖱️
- Rechtsklick: Flagge setzen oder entfernen 🚩
- Mittelklick: Debug-Ausgabe in der Konsole 🛠️
- `Reset`: Neue Runde starten 🔄
- `Reveal`: Nach einer Niederlage alle Bomben anzeigen 👀
- `Settings`: Farben für Hintergrund und Vordergrund anpassen 🎨
- Fortschrittsanzeige sowie Zähler für Bomben und Flaggen 📊

## Bedienung 🎮

1. Spiel starten ▶️
2. Mit einem Linksklick ein erstes Feld öffnen.
3. Mit Rechtsklicks verdächtige Felder markieren 🚩
4. Ziel ist es, alle sicheren Felder zu öffnen, ohne eine Bombe zu treffen.
5. Nach einer Niederlage kannst du mit `Reveal` die restlichen Bomben anzeigen oder mit `Reset` direkt neu beginnen.

## Spielregeln 📜

- Bomben werden erst nach dem ersten Klick erzeugt.
- Das erste Feld und alle direkt angrenzenden Felder bleiben frei ✅
- Eine Partie ist gewonnen, wenn alle sicheren Felder aufgedeckt sind und die Flaggenzahl der Bombenzahl entspricht 🏆
- Verloren ist das Spiel, sobald auf eine Bombe geklickt wird 💀

## Einstellungen ⚙️

Das Einstellungsfenster erlaubt aktuell die Anpassung von:

- Hintergrundfarbe 🎨
- Vordergrundfarbe 🖌️

## Steuerung 🕹️

| Eingabe | Aktion |
|---|---|
| Linksklick | Feld aufdecken |
| Rechtsklick | Flagge setzen / entfernen 🚩 |
| Mittelklick | Debug-Infos für das Feld ausgeben 🛠️ |
| `Reset` | Neues Spiel starten 🔄 |
| `Reveal` | Bomben nach Niederlage anzeigen 👀 |
| `Settings` | Farben ändern 🎨 |
